# Как обновить афишу на сайте

Афиша хранится в одном файле: `src/data/afisha.json`. Вы правите его на GitHub прямо в браузере. Программы ставить не нужно.
> Сайт ещё не опубликован. Шаги 4 и 5 начнут работать, когда сайт подключат к хостингу и он будет сам пересобираться после каждого изменения.

## 1. Открыть файл

1. Зайдите на github.com в репозиторий сайта.
2. Откройте папки `src` → `data` и файл `afisha.json`.
3. Нажмите на значок карандаша (Edit) справа вверху.

## 2. Добавить концерт

Каждый концерт — это блок в фигурных скобках `{ … }`. Блоки стоят в квадратных скобках `[ … ]` и разделены запятой.

Скопируйте образец и замените значения на свои:

```json
{
  "id": "jazz-2026-12-26",
  "date": "2026-12-26",
  "time": "19:00",
  "title": { "kk": "Жаңа жылдық джаз", "ru": "Новогодний джаз" },
  "ensemble": { "kk": "Джаз оркестрі · Виктор Шейкин", "ru": "Джазовый оркестр · Виктор Шейкин" },
  "genres": ["jazz"],
  "priceFrom": 3500,
  "ticketUrl": "https://ticketon.kz/place/pavlodarskaya-filarmonia",
  "image": "c-jazz.webp"
}
```

Если в файле пусто (`[]`), вставьте блок между скобками: `[ { … } ]`. Если концерты уже есть, поставьте запятую после последнего `}` и вставьте новый блок.

## 3. Что значит каждое поле

| Поле | Что писать | Пример |
|---|---|---|
| `id` | Короткое имя латиницей, без пробелов, своё для каждого концерта | `jazz-2026-12-26` |
| `date` | Дата: год-месяц-день, с нулями | `2026-12-05` |
| `time` | Время начала | `18:00` |
| `title` | Название на казахском (`kk`) и русском (`ru`), оба обязательны | |
| `ensemble` | Кто выступает, на двух языках | |
| `genres` | Жанры для фильтра, один или несколько: `sym` симфоническая, `folk` народная, `jazz` джаз, `choir` хор, `dance` танец, `kids` детям | `["folk", "kids"]` |
| `priceFrom` | Самая низкая цена в тенге, только цифры. `0` — вход свободный | `2500` |
| `ticketUrl` | Ссылка на концерт на Freedom Ticketon. Если ссылки нет, удалите строку целиком: будет ссылка на страницу филармонии | |
| `image` | Фото коллектива из папки `src/assets/img` | `c-symph.webp` |

Фото коллективов: `c-omarov.webp` (оркестр Омарова), `c-symph.webp` (симфонический), `c-jazz.webp` (джаз), `c-choir.webp` (хор), `c-nur.webp` («Нұр»), `c-shernyaz.webp` («Шернияз»), `c-lad.webp` («Лад»), `c-retro.webp` («Ретро»), `seats.webp` (зал).

Порядок концертов в файле не важен: сайт сам расставит их по дате. Прошедшие концерты удалять не обязательно, сайт их не показывает.

## 4. Сохранить

1. Нажмите зелёную кнопку **Commit changes**.
2. В поле описания напишите, что поменяли, например «Афиша на январь».
3. Нажмите **Commit changes** ещё раз.

## 5. Если что-то не так

Сайт проверяет файл перед обновлением. Если в нём ошибка, сайт **не сломается**: он просто останется прежним, а в сообщении о сборке будет написано, где ошибка. Например:

```
Ошибка в src/data/afisha.json:
  2.date: дата в виде 2026-12-05
```

Это значит: у третьего концерта (счёт идёт с нуля) дата записана неправильно.

Частые ошибки:
- нет запятой между блоками `}` и `{`;
- лишняя запятая после последнего блока;
- кавычки «ёлочки» вместо прямых `"`;
- цена в кавычках (`"3000"` вместо `3000`);
- забыли русское или казахское название.
