# Заметки по проекту: сайт Павлодарской областной филармонии имени Исы Байзакова

Краткий обзор и скриншоты в [README](../README.md). Пути ниже указаны от корня репозитория.

Новый сайт взамен [isa-philharmonic.kz](https://isa-philharmonic.kz). Сейчас это **дизайн главной страницы, свёрстанный в коде**: одна HTML-страница с реальными фото филармонии, переключателем казахский / русский и эффектами GSAP. Это ещё не рабочий сайт: афиша здесь пример, админки нет.

Здесь же история проекта, все принятые решения и что делать дальше, чтобы можно было продолжить без исходного чата.

## Быстрый старт

```bash
cd site
python3 -m http.server 8000
```

Откройте http://localhost:8000. Если Python нет, можно `npx serve -l 8000`.

Открывать через сервер, а не двойным кликом по файлу: GSAP (cdnjs) и шрифты (Google Fonts) грузятся из интернета.

Страница с анализом старого сайта, планом и серым каркасом лежит в `docs/plan/index.html`, открывается так же:

```bash
cd docs/plan
python3 -m http.server 8001
```

## Решения, принятые с заказчиком

Это ответы заказчика в исходном чате, менять их без согласования не стоит:

1. **Новый сайт полностью заменяет** isa-philharmonic.kz, а не дополняет его отдельной страницей.
2. **Первым открывается казахский язык**, русский включается переключателем ҚАЗ · РУС.
3. **Билеты продаются по ссылке на Freedom Ticketon**, без встроенного виджета.
4. Дизайн **«более modern, но без фанатизма»**, с **параллаксом и эффектами GSAP для вау-эффекта**, при этом **сохранить колорит филармонии**.

## Анализ старого сайта (кратко)

Смотрели в браузере на 1440 и 390 px, подробно в `docs/plan` на вкладке «Анализ».

- Блок «Афиша» на главной пустой, вместо него около 900 px белого поля. В «Репертуаре» только картинки-афиши без текста.
- «Купить билеты» ведёт на промежуточную страницу `loc_tiketon.php`, она не загрузилась за 45 секунд.
- На телефоне первый экран занимает юридическое название «Коммунальное государственное казённое предприятие…».
- Около 40 ссылок в шапке в две строки. Главная весит 4,4 МБ и грузится 6,3 с. Нет `lang` и meta description.
- Сильная сторона — материал: зал-памятник 1963 года на 428 мест, люстра, фойе в стиле рококо, восемь коллективов с хорошими фото, история с 1941 года.

## Дизайн

### Направление

- **Что это:** концертный зал на 428 мест в центре Павлодара, восемь коллективов, от кобыза до джаза.
- **Характер:** торжественный, тёплый, точный. Как вечер в этом зале, а не как госпортал.
- **Мир:** само здание. Три арки фасада, охра между белыми колоннами, лепнина с позолотой, хрусталь люстры, бордовые кресла, мятные панели фойе.
- **Фирменный приём:** арка фасада. Она есть в логотипе, в рамках фото главы «Зал», в превью и миниатюрах афиши, на карточке адреса. Других декоративных приёмов нет.

Фиолетовую палитру, которую предлагал скилл ui-ux-pro-max, сознательно отбросили: она не подходит к зданию, а скиллы taste и unslop запрещают фиолетовый.

### Шрифты

- **Prata** (Google Fonts): заголовки и крупные цифры. Дидона с поддержкой казахских букв Ә Ғ Қ Ң Ө Ұ Ү Һ І.
- **Golos Text** (Google Fonts): текст и интерфейс, рассчитан на кириллицу.

При замене шрифтов проверяйте казахские буквы: у многих шрифтов нет подмножества cyrillic-ext.

### Структура страницы

1. **Шапка.** Прозрачная над главным экраном, после 40 px прокрутки становится светлой. Пять пунктов, ҚАЗ · РУС, «Билет алу». На телефоне меню на весь экран.
2. **Главный экран.** Фото зала с люстрой, h1 «Иса Байзақов атындағы филармония», карточка ближайшего концерта и четыре факта (1941, 428 мест, 8 коллективов, сцена 8 × 8 м).
3. **Афиша.** Список концертов месяца с фильтром по жанрам (работает). В строке дата, день, миниатюра, название, коллектив, цена «от», кнопка «Билет».
4. **Коллективы.** Восемь коллективов: два крупно, шесть в сетке. Названия на казахском и русском, худруки.
5. **Зал.** Арка раскрывается на весь экран, дальше четыре главы: фойе, лепнина, люстра, 428 мест.
6. **85 лет.** Крупное «85», архивные фото, шесть вех с 1941 по 2026 год.
7. **Новости и проекты.** Три реальные новости с текущего сайта, проекты Самға, Тағылым, Ән аманат, Алтын бесік — туған ел.
8. **Посетителям.** Как купить билет, адрес со ссылкой на 2ГИС, контакты.
9. **Подвал.** Разделы, «О филармонии», документы (комплаенс, противодействие коррупции, госсфера, версия для слабовидящих).
10. **Нижняя панель на телефоне** с «Билет алу» и «Афиша». Появляется после главного экрана.

### Анимации (GSAP 3.12.5 + ScrollTrigger, код в конце `site/index.html`)

| Где | Что происходит |
|---|---|
| Главный экран | При загрузке фото слегка уменьшается, строки h1 выезжают снизу, остальное проявляется по очереди. При прокрутке фото уходит медленнее страницы (параллакс) |
| Афиша | На ноутбуке за курсором плывёт фото коллектива в арочной рамке (`gsap.quickTo`) |
| Коллективы | Фото чуть смещаются внутри рамок при прокрутке, при наведении увеличиваются на 3 % |
| Зал | Секция закрепляется, узкая арка с фасадом раскрывается на весь экран поверх слова «Зал» (`clip-path`), затем появляется подпись. Фото в арке меняется по главам через IntersectionObserver |
| 85 лет | Архивные фото плывут с разной скоростью (`data-speed`). На ноутбуке шесть вех едут горизонтально, а охристая линия показывает прогресс |

Правила, которых держались (по скиллу Эмиля Ковальски):
- анимируются только `transform`, `opacity` и `clip-path`;
- одна кривая `cubic-bezier(.23,1,.32,1)`;
- при нажатии кнопка сжимается до `scale(.97)`;
- эффекты при наведении включаются только на устройствах с мышью.

При `prefers-reduced-motion: reduce` GSAP не запускается, увеличения и сдвиги отключены. История тогда показывается сеткой, а не горизонтальной лентой.

Если GSAP не загрузился, страница остаётся рабочей и статичной: всё видно, ничего не спрятано.

### Языки

Казахский текст стоит прямо в разметке, русский — в атрибуте `data-ru` того же элемента. Подписи к картинкам хранятся в `data-ru-alt`, `aria-label` в `data-ru-label`. Скрипт меняет тексты, `lang` у `<html>` и запоминает выбор в `localStorage` (`phil-lang`). Добавляя текст, всегда пишите обе версии.

## Что на странице реальное, а что нет

**Реальное, взято с сайта филармонии и из новостей:**
- адрес, телефоны, e-mail, Instagram;
- названия коллективов и имена худруков;
- факты о зале: 1963 год, 428 мест (234 партер и 194 амфитеатр), сцена 8 × 8 м, высота 8,7 м, фойе 181,5 м², люстра;
- даты истории: 1941, 1943, 1946, 1950, 1965, 1971;
- три новости от 21 августа 2026;
- все фотографии.

**Пример, заменить до запуска:**
- **Афиша на декабрь 2026 целиком выдумана**: названия концертов, даты, время и цены. Настоящую программу найти не удалось. Коллективы и дирижёры в ней настоящие.
- Карточка «Ближайший концерт» на главном экране (5 декабря, «к 85-летию»). Дата выбрана потому, что первый приказ филиала издан 5 декабря 1941 года, но концерта в этот день никто не подтверждал.

## Следующий этап: рабочий сайт

Рекомендованный вариант из плана: **Astro + афиша в одном файле данных**.

- **Статический сайт.** Быстрый, хостится где угодно: Vercel, хостинг филармонии.
- **Афиша в одном файле.** Лежит в `src/data/afisha.json` или Google-таблице. Сотрудник правит строку, сайт пересобирается. Карточка «Ближайший концерт» берётся из афиши автоматически.
- **Два языка из одного шаблона.** Маршруты `/kk/` (по умолчанию) и `/ru/` вместо подмены через `data-ru`: так лучше для поиска.
- **Перенос страниц старого сайта.** «О филармонии», «Руководство», «Лица», «Новости», «Комплаенс», «Госсфера», «Вакансии», «Галерея». Это требование госучреждения, их нельзя потерять при замене.
- **Анимации.** GSAP лучше подключить из npm, а не с CDN.
- **Позже.** Можно подключить CMS для новостей.

Порядок работы, если продолжать с Claude Code и скиллами superpowers: `writing-plans` (план по задачам), затем `executing-plans` или `subagent-driven-development`, перед сдачей `verification-before-completion`.

Проект проверялся автоматическими проверками скилла taste-skill (`copy-lint.mjs`, `consistency.mjs`). Исправлено:
- контраст серого текста;
- обрезка казахских букв в h1;
- три действия на главном экране;
- размеры заголовков по уровням;
- разная высота кнопок;
- зоны нажатия на телефоне;
- видимость фокуса;
- запасной вид истории без JS.

Часть замечаний taste-skill оставлена сознательно. Это правила его собственного шаблона, они расходятся с решениями заказчика:

| Замечание | Почему оставлено |
|---|---|
| `effect-kind`: на сайте заведения ничего не должно двигаться при прокрутке | Заказчик попросил параллакс и GSAP |
| `phone-number`: реальный формат телефона | Это настоящие телефоны филармонии |
| `copy-headline`: h1 должен называть категорию («концерты») | h1 — официальное имя учреждения |
| `nav`, `collide`: прозрачная шапка над фото, логотип в две строки | Так задумано |
| `section-height`, `one-section`, `container-edges` | Правила сетки шаблона taste-skill, у этого сайта своя сетка |
| `photo-upscale` | Решается только оригиналами фото от филармонии |

## Скиллы Claude Code

Проект делался с этими скиллами, они ставятся скриптом `scripts/install-skills.sh`:

| Скилл | Репозиторий | Для чего пригодился |
|---|---|---|
| Emil Kowalski (20 скиллов: `emil-design-eng`, `animate`, `review-animations` и др.) | [emilkowalski/skill](https://github.com/emilkowalski/skill) | Правила анимаций, проверка движения |
| UI/UX Pro Max | [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | Чек-лист доступности, подбор шрифтов с казахскими буквами |
| Unslop | [heydamir/unslop](https://github.com/heydamir/unslop) | Направление дизайна (характер, мир, фирменный приём), аудит признаков «сайта от нейросети» |
| tasteskill | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) | Автоматические проверки в браузере |
| Superpowers | [obra/superpowers](https://github.com/obra/superpowers) | Брейншторм, планы, проверка перед сдачей |

```bash
bash scripts/install-skills.sh
```

С флагом `--project` скиллы ставятся в `.claude/skills` этого репозитория. Это удобно, если в облачном Claude Code нет доступа к домашней папке.

Скилл taste-skill запускает свой Chromium. От root (например, в контейнере) Chromium требует `--no-sandbox`: сделайте обёртку и передайте её в `CHROME_PATH`, не правя файлы скилла.
